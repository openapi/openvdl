# Round 0001 - Bootstrap

Status: open

## Goal

Establish the purpose and method of the OpenVDL exploration diary.

## Motivation

OpenVDL aims to maintain validators that may evolve in response to
real-world changes. Modern LLM and agentic tooling makes it practical to
run repeated explorations over those changing domains.

The project therefore needs a place to record:

- what was explored
- what was suspected
- what evidence was considered
- what was promoted into validator semantics

## Hypothesis

A maintained validator ecosystem benefits from keeping a research diary
separate from, but linked to, the semantic validator definitions.

## Outcome So Far

- the exploration diary directory was created
- the distinction between semantic facts and exploration history was made explicit
- the repository now has a place to track iterative fact discovery

## Next Link

Future validator changes should reference exploration rounds when a
discovered fact materially influences validation behavior.
