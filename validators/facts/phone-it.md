# Italian Phone Numbering Notes

Status: placeholder

This file is an example of the kind of note the maintained validator
library should keep when a real-world fact may affect validation.

Example category:

- mobile numbering changes
- reserved prefixes
- decommissioned ranges
- carrier or regulatory constraints

This placeholder intentionally does not assert any concrete numbering
fact. It exists to establish the pattern:

1. discover a fact
2. document it
3. trace the validator change back to that fact

When this repository starts tracking authoritative numbering facts, this
file or sibling files can evolve into structured change notes.
