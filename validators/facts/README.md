# Maintained Facts

This directory is for real-world observations that affect validator
behavior.

These are not validator definitions by themselves. They are supporting
artifacts that document why a validator library changed.

Typical content:

- policy changes
- numbering plan changes
- registry changes
- deprecations
- provider-specific quirks

Each fact note should try to capture:

- subject area
- statement
- impact on validation
- confidence level
- source or rationale
- date observed

OpenVDL should avoid silently embedding world assumptions without
traceability.
